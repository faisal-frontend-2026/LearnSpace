# LearnSpace

LearnSpace is an educational landing page for beginners who want to learn the fundamentals of web development step by step. It introduces learning paths for HTML, CSS, and JavaScript, and explains the project's approach to learning.

## Features

- A welcoming hero section that introduces LearnSpace.
- Learning path cards for HTML, CSS, and JavaScript.
- A section highlighting the benefits of structured, practical learning.
- An about section with a link to the learning paths.
- A responsive layout for different screen sizes.

## Technologies

- HTML for page structure and content.
- CSS for styling and responsive layouts.
- Font Awesome for icons.
- Cairo and Space Mono fonts from Google Fonts.

## Run the Project

No packages or server setup are required:

1. Download or copy the project files to your computer.
2. Open `index.html` in a web browser.

An internet connection is required to load the fonts and icons.

## Project Structure

```text
My-First-Project/
├── index.html
├── style.css
├── README.md
└── images/  (learning.jpg and other image files)
```

The images are used as backgrounds for the learning path cards and the about section in `style.css`. To replace an image, put the new file in the `images` folder and update its CSS path if its filename changes.
